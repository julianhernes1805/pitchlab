What Works · What's Approximate · What Needs Backend

WORKS: Mic device enumeration (all USB/built-in inputs), VU metering (RMS/dBFS/peak hold/clipping), YIN pitch detection (real-time, 30ms frames), melody segmentation with hysteresis + confidence, Melodyne-style blob visualization, score system, lyrics display (LRC time-synced + plain text), ID3v2 parsing (title/artist/cover art/embedded lyrics USLT).
APPROXIMATE: Vocal isolation = center-channel (L+R)/2 — captures centered vocals in stereo mixes, unreliable for hard-panned or complex arrangements (not ML). BPM detection ±2BPM typical. Key detection via Krumhansl-Schmuckler profiles, misidentifies parallel keys ~15% of time.
REQUIRES BACKEND / ML MODEL: True vocal stem separation (Demucs/Spleeter — needs server or WASM). External lyrics (Genius/Musixmatch APIs — CORS proxy required). Cloud leaderboard. Recording export.
